# 川麻训练器 (Sichuan Mahjong Trainer)

参考德扑训练器做的第二个牌类训练器。定位是**练牌感**：不赌钱、不算番数排名，
就是让你在每一手都能看到「现在离听牌还差几次换牌、哪些牌能推进一步、这张该不该打」。

规则口径是**四川麻将（血战到底）**，决策辅助按用户要求只做**向听数 + 有效进张**。

## 快速开始

在 DSH 侧栏「更多」菜单点「游戏」→ 面板里的「麻将」tab，或直接打开 `http://127.0.0.1:3080/game/mahjong/`
（需 DSH 登录；后端 8817 只监听 127.0.0.1）。开局先**定缺**，然后点手牌打出；
能碰/杠/胡时中间会出现按钮。
右侧面板实时给出向听数、有效进张和每张可打牌的对比。

快捷键：`Esc` 关掉结算弹窗。

## 牌面的两套表示

`Tile.code` 是 `4m` 这种**紧凑编码**，只在接口传输、牌墙、进张数据里用；
`Tile.name` 是 `四万` 这种**汉字读数**，**所有给用户看的地方都用它** ——
碰/杠按钮、推荐打哪张、每张牌的对比表、出牌记录、牌的悬停提示。
牌桌上说「碰四万」，没人说「碰 4m」。改动显示逻辑时别把 `code` 直接印出来。

## 决策辅助怎么用

**向听数**：离听牌还差几次换牌。`0` 就是已经听牌，面板会把数字标绿。

**有效进张**：哪些牌能推进向听，以及牌墙里还剩几张。口径是

```
剩余张数 = 4 − 河里明牌 − 亮出的面子 − 自己手里的
```

**别人手里的牌不扣** —— 那属于未知信息，扣了就成作弊了（会把进张算得虚高）。

**推荐打哪张**：按 `(向听数, -有效进张)` 排序，金框标出的是并列最优的那几张。
并列最优很多是正常的（同向听、同进张），面板会说明「打哪张都一样」。
「每张可打牌的对比」表格把全部选项摊开，方便你看清「差一点点」的取舍。

**定缺的影响**：定缺那一门整门按死牌处理（不参与进张、必须优先打完），
所以面板的进张里不会出现缺门牌。

## 规则（v1）

- **108 张**：万 / 条 / 筒 各 1–9，每种 4 张，没有字牌。
- **定缺**：开局每人定一门，缺门牌必须先打完，胡牌时手里不能有缺门牌。
- **不能吃**，只有碰 / 杠 / 胡。
- **杠**：明杠（碰别人的）、暗杠（手里 4 张）、补杠（碰过之后摸到第 4 张），杠完补一张。
- **血战到底**：有人胡牌后其余家继续打，直到只剩一家没胡或牌墙摸完。
- **番型**取最大的那个做倍数结算：平胡 1 / 对对胡 2 / 金钩钓 2 / 七对 4 /
  清一色 4 / 龙七对 8。自摸三家赔，点炮放炮那家赔。

## 项目结构

```
mahjong/
├── tiles.py      108 张牌的定义、idx 编码、`code`（机器）/ `name`（汉字读数）
├── hand.py       向听数 / 有效进张 / 胡牌判定（核心算法）
├── game.py       4 人对局状态机：定缺 → 摸打 → 碰杠胡 → 血战到底
├── ai.py         用同一套向听+进张驱动的对手
├── web.html      牌桌页面（自包含，由 app/api/routes/mahjong.py 直接返回）
├── test_hand.py  算法测试（对拍独立参考实现）
└── test_game.py  对局测试（自对弈不变量）
```

HTTP 层在插件的 `server/app/api/routes/mahjong.py`（`/mahjong` 页面 + `/mahjong/api/*`）。
包内一律**相对导入**（`from .hand import …`）—— 模块名（`game`、`ai`、`hand`）太通用，
直接放顶层会撞名。

## 算法要点

**向听数**：按门（万/条/筒）枚举 `(面子数, 搭子数, 是否含将)` 的所有切法并 `lru_cache`，
跨门合并取 `8 − 2×面子 − 搭子` 的最小值（`面子 + 搭子 = 5` 且无将时 +1）。
拆成 3 个 9 维而不是 27 维全搜索：三门互不干扰，再靠缓存把反复出现的同门牌型摊掉。

**龙七对**：4 张同牌算**两对**（`sum(n // 2)`）。日麻七对子要求 7 种互不相同的对子，
川麻不是 —— 第一版照日麻写，`1111m22m33m44m55m66m` 被判成不胡。

**定缺**：整门当孤张。标准向听公式本就假定手牌 13/14 张、每张都可参与组合；
缺门牌当死牌正好等价于「每次摸打都要换掉一张」，所以不必给公式开特例。

## 已知边界（v1 有意不做）

- **查大叫 / 花猪 / 刮风下雨**的结算没实现（只算番型倍数）。
- **抢杠胡**、**杠上开花**、**呼叫转移**、**换三张** 未实现。
- **一炮多响**：只允许优先级最高的一家胡（真实川麻可以多家同时胡同一张）。
- 对局只存内存、不落库，重启即清。

这些都在 `mahjong/__init__.py` 的包文档里列了一份，改之前先看那里。
